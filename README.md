## 📌 Sobre o projeto

O **StudyFlow** é uma aplicação web desenvolvida para ajudar pessoas a organizar seus objetivos de estudo, definir prazos e acompanhar sua evolução ao longo do tempo.

O projeto surgiu durante a imersão da Alura, com foco não apenas no desenvolvimento da aplicação, mas também na importância de estruturar ideias e requisitos antes de iniciar a implementação.

A proposta foi utilizar a inteligência artificial como ferramenta de apoio ao desenvolvimento, aplicando técnicas de elaboração de prompts mais eficientes para obter resultados consistentes e reduzir retrabalho durante futuras alterações.

## 🎯 Objetivos do projeto

- Transformar ideias iniciais em requisitos claros e objetivos.
- Elaborar prompts mais eficientes para orientar o desenvolvimento com IA.
- Definir critérios e especificações antes da implementação.
- Compreender a diferença entre requisitos funcionais e não funcionais.
- Conhecer a estrutura de uma aplicação web.
- Implementar operações CRUD para gerenciar informações.
- Facilitar futuras alterações por meio de uma definição mais precisa das funcionalidades.

## ✨ Funcionalidades

### 📋 Gerenciamento de objetivos

- Cadastrar objetivos de estudo.
- Visualizar os objetivos cadastrados.
- Editar informações dos objetivos.
- Acompanhar o status de cada objetivo.
- Marcar objetivos como concluídos.
- Reabrir objetivos concluídos.

### 📊 Acompanhamento do progresso

- Visualizar o total de objetivos cadastrados.
- Identificar objetivos não iniciados.
- Acompanhar objetivos em andamento.
- Contabilizar objetivos concluídos.
- Visualizar o progresso geral dos estudos.

### 🗂️ Organização visual

- Filtrar objetivos por status.
- Consultar prazos definidos para cada objetivo.
- Visualizar descrições e informações relacionadas às metas de aprendizagem.

## 🧠 Engenharia de software com IA

Um dos principais aprendizados da imersão foi compreender que a qualidade de uma aplicação começa antes da escrita do código.

Uma ideia inicial precisa ser transformada em instruções claras, critérios verificáveis e especificações que orientem o desenvolvimento.

No StudyFlow, essa abordagem envolve os seguintes conceitos:

### 1. Engenharia de prompts

A elaboração de prompts mais eficientes ajuda a orientar a IA com instruções específicas, contexto suficiente e resultados esperados bem definidos.

Isso facilita a comunicação com a ferramenta e pode reduzir o retrabalho quando uma funcionalidade precisa ser alterada.

### 2. Especificações e critérios

Antes de implementar uma funcionalidade, é importante definir seu objetivo, suas regras de negócio, suas limitações e os critérios que determinam se ela está funcionando corretamente.

### 3. Requisitos funcionais e não funcionais

**Requisitos funcionais** descrevem o que o sistema deve fazer.

Exemplos no StudyFlow:
- Permitir o cadastro de objetivos.
- Permitir a edição de objetivos existentes.
- Permitir a alteração do status de um objetivo.
- Exibir indicadores de progresso.

**Requisitos não funcionais** descrevem características de qualidade e restrições do sistema.

Exemplos que podem orientar a evolução do projeto:
- Interface intuitiva e fácil de utilizar.
- Código organizado e de fácil manutenção.
- Proteção de credenciais e informações sensíveis.
- Atualização consistente dos indicadores apresentados.

### 4. Estrutura de software

A definição das tecnologias e da organização do projeto contribui para uma implementação mais estruturada, facilitando a manutenção e a evolução das funcionalidades.

### 5. CRUD

O CRUD representa quatro operações fundamentais para a manipulação de dados:

| Operação | Significado | Aplicação no StudyFlow |
|---|---|---|
| Create | Criar | Cadastrar um objetivo de estudo |
| Read | Ler | Consultar os objetivos cadastrados |
| Update | Atualizar | Editar um objetivo ou seu status |
| Delete | Excluir | Remover um objetivo, caso essa funcionalidade esteja implementada |

O CRUD ajuda a estruturar as operações de gerenciamento de informações de maneira organizada e previsível.

## 🛠️ Tecnologias utilizadas

- **TypeScript:** linguagem utilizada para o desenvolvimento, com tipagem estática.
- **React:** biblioteca para construção da interface baseada em componentes.
- **Vite:** ferramenta de desenvolvimento e compilação da aplicação.
- **Google AI Studio:** ambiente utilizado para apoiar o desenvolvimento com inteligência artificial.
- **GitHub:** plataforma utilizada para versionamento e armazenamento do código.
